# UI Sitemap & Wireframes

## Sitemap
- `/` Dashboard (market heatmap, index cards, sticky search)
- `/stock/[symbol]` Tabbed stock detail
- `/compare` Side-by-side comparison (up to 4)
- `/portfolio` Holdings, allocation, risk, SIP
- `/screener` Filters + results table
- `/watchlist` Alerts and tracking
- `/settings/profile` risk profile + mode
- `/disclaimer` Data accuracy & disclaimer

## Stock Detail Wireframe
1. Sticky header: search, mode toggle, market selector.
2. Hero: symbol, price, daily change, recommendation card.
3. Tabs:
   - Overview: profile + quick stats + catalyst cards.
   - Fundamentals: charts and 10Y table.
   - Financials: annual/quarterly statements.
   - Valuation: multiples, DCF controls, sensitivity heatmap.
   - Technicals: candlestick + overlays + signals.
   - Peers & Industry: benchmark table and rankings.
   - News + Sentiment: cards and polarity filter.
   - AI Insight & Recommendation: summary/pros/cons/assumptions.
   - Events: timeline.
   - Ownership: trend charts.
4. Footer disclaimer and export actions (PDF/XLSX).

## Beginner Mode
- Reduced chart density, plain-language cards, default glossary expanded.

## Pro Mode
- Full statement tables, raw data, advanced indicators, CSV export.
